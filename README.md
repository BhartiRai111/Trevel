# Roamora

Travel website built with Next.js (App Router) and TypeScript. Design: Teal Lagoon colours with a Glass Tabs hero.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
```

- `app/` page, layout and global CSS
- `components/` Hero (booking tabs), Destinations, Featured, modals and other sections
- `lib/places.ts` destination data and photo links (Unsplash)
- `public/hero.mp4` optional: add a travel clip and it plays over the hero photos
- `design/templates.html` the 10 hero templates that were reviewed
